# 📱 Simulador de Red Social

## Descripción
Aplicación en Python que simula el funcionamiento de un feed de red social
utilizando listas enlazadas simples, circulares y doblemente enlazadas.

## Requisitos
- Python 3.8+
- Tkinter (incluido en Python)

## Estructura del Proyecto
- `estructuras/` - Listas enlazadas implementadas manualmente
- `logica/` - Lógica de negocio y gestión de datos
- `interfaz/` - Interfaz gráfica con Tkinter
- `data/` - Base de datos JSON

## Cómo Ejecutar
```bash
python main.py
